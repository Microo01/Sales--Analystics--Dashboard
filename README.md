# Sales Analytics Dashboard

## Project Overview
An interactive Sales Analytics Dashboard built using Microsoft Power BI and Excel to analyze sales performance, profit, orders, quantity, categories, regions, payment modes, and top-performing products.

## Tools & Technologies
- Microsoft Power BI
- Microsoft Excel
- Data Analysis
- Data Visualization
- Pivot Tables
- DAX

## Dashboard KPIs
- Total Sales
- Total Profit
- Total Orders
- Total Quantity

## Key Analysis
- Sales by Category
- Profit by Category
- Monthly Sales Trend
- Sales by Region
- Top 10 Products
- Payment Mode Analysis
